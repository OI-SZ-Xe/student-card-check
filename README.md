# 请出示学生证

深圳实验中学 · 校门检查站 · 学生会纪检部。一款 Papers, Please 式的证件审核游戏：在 30 天里核对证件、盖章放行或拒绝，同时应付配额、贿赂、组织线与自己的钱包。

- 引擎：Godot 4.7（`4.7.2-stable`），GDScript，纯代码构建 UI
- 平台：Windows / Android / Web（HTML5）
- 在线试玩：<https://oi-sz-xe.github.io/student-card-check/>
- 许可证：GNU AGPL-3.0（见 [LICENSE](LICENSE)）

## 目录结构

```
project.godot          工程入口（自动加载 Data/State/SaveManager/Meta/Music/Settings/Sfx）
scenes/main.tscn       唯一场景，其余界面全部由脚本构建
scripts/
  autoload/            全局状态、存档、跨周目档案、音频与设置总线
  screens/             Desk（检查台）、Intro（开场动画）
  systems/             RuleEngine（纯函数规则）、VisitorFactory（可复现的访客生成）
  ui/                  证件、手册、终端、印章、对话框等控件
data/                  访客姓名、学校与签名、规则、手册、升级、签名表（JSON）
art/                   像素立绘、字库图集、道具、签名样本
audio/                 程序生成的 BGM 与环境音
tools/                 生成贴图、字库、签名、音效的 Python 脚本
tests/                 headless 单元测试
docs/                  截图与测试报告
```

## 从源码运行

```bash
godot --path .            # 4.7 以上
```

首次运行会自动导入资源（字库图集较大，约数秒）。

## 构建

```bash
# Windows 单文件
godot --headless --path . --export-release "Windows Desktop" "build/请出示学生证.exe"
# Android（需 Android SDK + JDK 17）
godot --headless --path . --export-debug "Android" "build/android/请出示学生证.apk"
# Web
godot --headless --path . --export-release "Web" "build/web/index.html"
```

导出预设见 `export_presets.cfg`。构建产物不入库，通过 Releases 分发；网页版部署在 `gh-pages` 分支。

## 测试

```bash
godot --headless --path . --script res://tests/run_tests.gd
```

40 条断言，覆盖规则引擎、访客生成可复现性、转学签名校验、伪造率与文档门槛。

## 玩法要点

- 每天 600 秒、10 位访客；第 7 天起有拒签配额
- 证件材料（校园卡、通行证、准入证、介绍信、健康证明）以独立卡片提交，可拖动核对
- 工具：对照模式、放大镜、紫外灯、电话核实、教育局档案、读卡器
- 第 12/19/26/30 天有枪械事件，第 30 天的选择决定结局
- 六种结局与跨周目继承

## 已实现（M0 垂直切片）

- 入职登记：开场前填写姓名与班级，写入考核表、录取通知、HUD 与存档。
- 开场（约 30 秒，可跳过）：学校第 7 号通知 → 入职考核表（笔试/面试/政审/体检/宣誓 五项逐个盖章，审核人=校长王明并附手写签名）→ 录取通知（打印玩家姓名与班级、准予入职章）→《纪检部学生指导短片》片头（3-2-1 计数）+ 三张守则字卡 → 标题。全片无人物剪影，纯排版、表单、公章与胶片颗粒。
- 检查亭桌面：访客窗口（程序化立绘）、学生证（可拖动）、印章台、桌面工具、值班台账、教育局办公系统。
- 规则引擎：有效期、出生年/年级、学号前缀、照片换脸/镜像、校园卡、临时通行证、准入证、介绍信双签与钢印、健康证明。日期一律使用**游戏内日期**。
- 判定与结算：允许/拒绝、正确奖励、错误罚款、每日结算、30 天流程、四种结局（负债/腐败/枪毙/平稳）。
- 对照模式：点两个字段做算术比对，每次扣 2 秒。
- 教育局终端（7 站点）：学校信息库（校长/教导主任/总机）、电话簿、准入规定（按天生成版本并保留旧版）、协查通报、档案查询（学号/姓名，计 3 秒）、收件箱（每日简报）、成就。未买「快捷收藏夹」须先进浏览器再进站点。
- 签字体系：五校校长 + 五位教导主任双套签名；转学介绍信校验教导主任签字。
- 仿真手册（M 键）：9 章，含年级对照表、五校长签名样本、伪造手法、奖惩标准、通话目录、升级清单。
- 办公用品商店：7 项升级，效果全部接入（时间、便签拨号、放大镜、档案索引、队列预检、紫外线灯、印章识别器）。
- 签名资产：系统书法字库（华文行楷 / 楷体 / 仿宋）逐字渲染，按校长参数做倾斜、错位、墨晕、飞白与落款横线，输出为 `art/signatures/*.png`；可直接替换为真人扫描件。
- 伪造签名：真迹 / 缺笔 / 浅墨 / 无钢印 / 镜像 五种变体，转学介绍信随机选用；点证件上的「查看介绍信」可看双签原件，用紫外线灯验压痕、放大镜验墨色与方向。
- 存档：3 槽位占位（当前 UI 使用 1 号槽），带 `save_version` 迁移入口。
- 程序化音效：盖章、纸页、打字、错误、提示。

## B/C 阶段（本轮）

- 每天 600 秒、固定 10 人、首日入职预支 30 元
- 升级按天开放：D3 快捷收藏夹 20 / D6 高级宿舍 100（免水电）/ D9 便签 30；检查工具 D12 起售
- 第 25 天开启没收：伪造介绍信直接没收，正常介绍信顶着 25 元罚款没收（逃亡前置）
- 逮捕章：伪造者 +20（正义感 +10），误捕 −30 并加怀疑度
- 组织线六封信（D3/7/12/18/22/28）：帮助 = 信任 +1（D12 需捐 50），举报 = 嘉奖 +10 怀疑度 −2
- 配额：第 7 天起每日拒签指标，未达标 +3 怀疑度并收到安全部警告
- 六种结局：负债 / 腐败 / 逃亡 / 革命 / 忠诚枪毙 / 忠诚平稳；逃亡需 25 天后、有正常介绍信、余额 ≥150，顶栏出现「启动逃亡」
- 天赋：经济头脑 / 正义感 / 洞察力，注册时选择

## D 阶段（本轮）

- 证券交易所（终端第 8 站）：5 支股票，每日 ±5% 波动，40% 概率触发财经新闻，价格限制在发行价 50%~200%
- 保证金交易：下单扣「价 × 股数 ÷ 杠杆」，杠杆 1x/2x/3x/5x；平仓返还保证金 + 浮动盈亏
- 爆仓：亏损吞掉保证金即强制平仓，当日新闻里会写「强制平仓 N 笔」
- 升级「一键填写交割单」：选股自动填现价与 10 股
- 贿赂事件：判错且文件伪造时 30% 触发，收下 +20 / 腐败 +1，推回照罚 10，叫校警 +20
- 股票与持仓写进存档

## E/F 阶段（本轮）

- 成就系统：14 枚，终端「成就」页显示已解锁/未解锁与进度；逮捕、没收、通话、比对、完美执勤、组织帮助、举报等都会解锁并弹条
- 风味事件：每日 50% 概率的一条校园琐事，在简报后进消息栏
- 组织邮件进收件箱：不再弹窗，改为「收件箱 → 处理这封邮件」，处理要花打开终端的时间
- 美术：检查亭加了窗框、竖棂、横档、编号牌、通话栅格与玻璃反光；工具按钮配像素图标；面板加投影；字体关闭抗锯齿做点阵感

## 道具与主题（本轮）

- 桌面道具实体化：工具栏换成木质托盘（六个凹槽对准六个按钮），印章台换成两枚像素印章（木质手柄 + 绿/红印泥环），电话是托盘右上角的像素话机（点开拨号），台账右下角是抽屉（点开证物袋，列出没收记录）
- 全局主题：LineEdit / OptionButton / PopupMenu / 滚动条统一成 CRT 深绿描边样式，桌面侧不再用引擎默认皮肤
- 窗口默认改为 1920×1080 原生分辨率（此前 1280 缩放导致字发虚），配合关闭抗锯齿，小字号变清晰

## 点阵字库（本轮）

- `tools/gen_font.py` 扫描全部脚本与 JSON，收集 1052 个字符（汉字 + ASCII + 标点）
- 用 SimSun 在 18 个字号（13/14/15/16/17/18/20/22/24/26/30/32/34/46/48/62/76/96）逐字烘焙，阈值二值化，货架算法打包成图集，输出 BMFont `.fnt` + PNG
- 运行时 `Ui._pick(font, size)` 按字号精确命中对应字库（不做缩放），未命中的字号与缺字回退到系统字体
- 效果：UI 文字与标题都是硬边像素字，不再有抗锯齿发虚

## 窗口与字库修补（本轮）

- 检查亭窗口换成像素走廊背景：卷帘门、公告栏、挂钟、海报、地脚线，玻璃后面再压一层暗色玻璃与文字底衬，人物立绘站在玻璃后
- 字库补了 11/12 两档，共 20 档；按字号懒加载（之前一次性加载全部 20 套导致启动 30 秒无响应，已修）
- 富文本改为按词智能换行，中文断行不再从词中间劈开
- 隐藏了未购置档案卡时的占位提示，窗口文字不再和背景打架

## 窗外（本轮）

- 走廊里加了排队学生的像素剪影（四个，带书包），站在玻璃后，轻微上下浮动
- 玻璃暗色层做 3.4 秒循环的呼吸明暗，模拟走廊灯管的工作状态

## 后半程事件（本轮）

- 枪械事件扩成四场：D12 校门冲击（2 名冲击者 + 3 名学生）、D19 夜间巡逻（1 名，5 秒，画面压暗）、D26 组织成员闯入（1 名袖标人员，开枪则信任 −3 / 怀疑度 +15，不开枪信任 +1）、D30 校门总攻（3 名，结束后直接进结局）
- D30 是否击中组织成员会覆盖结局判定：打中即「忠诚·枪毙」
- 黑市（终端第 9 站，第 20 天开张）：伪造介绍信 50 元、高铁票 100 元；逃亡按钮改为必须同时持有这两样 + 一封没收的正常介绍信
- 手册新增「十 · 结局图鉴」「十一 · 成就」两页

## 结局演出（本轮）

- 六种结局各有专属印章：隔离审查 / 开除学籍 / 执行枪决 / 准予留任 / 准予通行 / 新秩序
- 面板含绝密抬头、档案编号、统计（余额、天数、正确审核、没收数、信任、怀疑度、腐败）、结局图鉴进度
- 结局写入 `endings_seen` 并持久化，手册「结局图鉴」页显示【已解锁】/【未解锁】
- 触发结局时不再弹出成就提示条，避免和档案纸重叠
- 配额未达标累计超过 5 天，即使没帮组织也会被判「忠诚·枪毙」

## 稳定性（本轮）

- 字库只保留 11–48 共 17 档；62/76/96 一律映射到 48 档（最近邻放大，仍是像素块），图集数量与显存下降
- `--shot` 截图等待从 1.9 秒延长到 4 秒，冷启动不再偶发截空
- 实测冷启动到截图 9.2 秒（含 4 秒固定等待），连续三次稳定
- 修掉一个真 bug：`State.confiscatedNormalLetters` 与 `confiscatedItems` 从未声明，没收正常介绍信会在运行时抛错；已补字段并纳入存档

## 多周目与音频（本轮）

- `Meta` 自动加载：把 `runs`、上周目天赋、已解锁结局、成就、最高天数写进 `user://meta.json`
- 第二周目起：入职登记页提示「第 N 周目：继承上周目天赋 …… 伪造率 +15%」，天赋自动预选，伪造率通过 `VisitorFactory.forgery_bonus` 生效（单测默认 0，不受影响）
- 音频：程序生成 4 段循环——`bgm_day`（32 秒小调铺底）、`bgm_tense`（24 秒脉冲）、`amb_room`（20 秒房间底噪 + 挂钟）、`amb_rain`（15 秒雨声）
- `Music` 自动加载负责交叉淡入淡出：桌面播 day，枪械事件切 tense，事件结束切回，结局切到房间底噪；雨天日环境层换成雨声

## 音量与统计（本轮）

- 桌面台账右上角「设置」打开四路音量滑杆，实时生效
